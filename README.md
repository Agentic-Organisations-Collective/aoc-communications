# aoc-communications

Public-facing communication of the Agentic Organisations Collective, separated
from the legal and member domains. It publishes outward-facing communication
produced from governed source material.

## Packages

- `event-teasers` — public teasers and short previews for upcoming events
- `announcements` — official public announcements
- `press` — press-facing material and media communication
- `website-content` — editorial content published on the public website
- `social-posts` — short-form posts for social channels

## Governance

Public read, maintainer write. Outward-facing communication is published by the
board rather than written directly by every member; member contributions are
taken in through review. This repo may consume released content from governance,
but not the other way around.

## Tasks

**To-dos are GitHub issues in this repository** — not markdown checklists, not an
external to-do app. Board resolution of 2026-08-26.

Belongs here: outward-facing public communication — announcements, press material,
public website content, social posts. Event planning and event-related promotion go to
`aoc-curation`; the overall content plan is kept by the board in `aoc-board`.

**This repository is public.** Nothing that is not meant for the public belongs in an
issue here — no member data, no addresses, no internal deliberation. Those go to
`aoc-board`.

An issue names the occasion, the concrete task and its preconditions. Assign whoever
took the task on; where that is unclear, prefer no assignee over the wrong one. Tasks
from a meeting carry a `sitzung:<YYYY-MM-DD>` label and cite the minutes in a footer.
